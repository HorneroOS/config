# config

Official desktop configuration, defaults and reusable system settings for
Hornero OS.

## What belongs here

Generic, reusable defaults that define the Hornero desktop out of the box —
for example Hyprland defaults, terminal configuration, shell defaults, GTK
settings, default applications, font configuration and common desktop
behavior and scripts.

Much of this will be extracted over time from the generic parts of
[ulises-jeremias/dotfiles](https://github.com/ulises-jeremias/dotfiles).
That migration has **not** happened yet.

## What does NOT belong here

Anything specific to one person's workstation, applications or preferences.
Personal configuration stays in the dotfiles repository and must not be
migrated blindly.

## Why `config` and not `dotfiles`

Hornero OS is a Linux distribution, not a dotfiles collection. This
repository holds curated product defaults; the desktop shell itself lives in
[HorneroOS/shell](https://github.com/HorneroOS/shell) and distribution
composition in [HorneroOS/hornero](https://github.com/HorneroOS/hornero).

## Status

Early scaffolding. No configuration has been extracted here yet.
