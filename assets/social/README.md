# Repository social previews

1280x640 Signal Night cards for every public HorneroOS repository, generated by
`scripts/render-social-previews.py --png` from `assets/brand/logo-dark.svg` and
the flagship Night roles. The SVG is the source, the PNG is what GitHub needs.
`tests/test_brand.sh` fails when an SVG drifts from the generator.

These files are not packaged (`assets/brand` is; `assets/social` is not).

## Upload (maintainer, manual)

GitHub exposes no REST or GraphQL endpoint to set a repository social preview,
so each image is uploaded in the web UI: repository **Settings > General >
Social preview > Edit > Upload an image**. For the organization avatar use
`org-avatar.png` (500x500, from `icons/hornero-system.svg`; Settings > Profile). The current avatar is a pixel-art hornero on a pre-Signal clay palette; swapping it is the maintainer's call.

| HorneroOS/shell | `shell.png` |
| HorneroOS/config | `config.png` |

| HorneroOS/docs | `docs.png` |

Rendering needs IBM Plex Mono, IBM Plex Sans and IBM Plex Sans Condensed
(`ttf-ibm-plex`) and `rsvg-convert`.
